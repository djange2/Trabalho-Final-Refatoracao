# ADR-002: Usar YOLO (ultralytics) como Backbone de Detecção



## Contexto

Precisamos detectar jogadores e bola em tempo real (ou próximo disso) em vídeos
de futebol HD (1080p, 30fps). A equipe não tem recursos de tempo nem dados
para treinar um detector do zero. Requisito principal: detectar pessoas com
alta recall mesmo em grupos densos (jogadas de bola parada).

## Decisão

Usamos YOLOv8 via biblioteca `ultralytics`. Para jogadores: modelo genérico
`yolov8s.pt` (treinado no COCO, classe `person`). Para bola: modelo customizado
`ball_tracker.pt` treinado especificamente no domínio futebol, com melhor
precision em bolas pequenas e parcialmente ocluídas.

A abstração `BaseYoloDetector` unifica a lógica comum de inferência, permitindo
que `YoloDetector` e `BallDetector` compartilhem o método `_run_inference`
sem duplicação.

## Consequências

**Benefícios:**
- Estado da arte em detecção em tempo real (YOLO família)
- API unificada para qualquer variante YOLOv8 via `ultralytics`
- Suporte nativo a GPU (CUDA) e batch inference (decisivo para performance)
- Fine-tuning possível sem mudar a interface do detector

**Custos:**
- Dependência de biblioteca pesada (~500MB entre os dois modelos)
- Modelos customizados precisam ser retreinados ao mudar câmera/iluminação
- `yolov8s.pt` detecta torcedores como jogadores (mitigado pelo `DetectionFilter`)
